Professor scope changes do not alter administrative eligibility review or allocation endpoints. Every new interaction is linked to a real route above; the final browser inventory records rendered controls and destinations.

PROF-UI-08 extends verification to the shared header, account/notification menus, mobile drawers and administration navigation, in addition to main content. The [independent control inventory](https://github.com/najib-attar/resource-allocation-system/blob/937adcc75e23af79e37c394c932e99bc330e6a1b/docs/professor-services/PROF-UI-08/browser/control-trace.json) and browser results record actual visible states, action names, endpoints and actor-scoped destination checks. The administrator saved confirmation is verified in pending, eligible and eligibility-rejected states; only the eligible state presents an explicit Run Allocation Now POST. Unknown IDs use the shared 404 recovery interface. Long declared titles are tested in this component at all five widths.

The audit preserves all supported professor services. Academic notifications, cancellation and versioned published replacements remain deferred. Details of confirmed defects, canonical gateway enforcement, migration reversal and executed tests are maintained in the existing [acceptance report](acceptance-report.md) and [backend matrix](traceability.md).
