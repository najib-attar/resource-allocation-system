# Approved screen-to-backend matrix

The [capability matrix](coverage.md) expands every authorized action. [Route inventory](UI-09/routes.md) accounts for all service rules and staff-only boundaries. The table below maps all 24 design references, including the explicitly proposed aggregate and state gallery. Exact per-screen test modules are in [CSV](screen-coverage.csv).

| Screen | Existing route / service | Frontend | Preserved actions / status |
|---|---|---|---|
| Student Home | `/student/` / StudentDashboardService.load | [student_home.html](../../../web/templates/student_home.html) | Five services, own appointment/room progress and compact schedule. **Implemented / preserved** |
| My Activity | `/student/#my-activity and existing service indexes` / Existing scoped Home model and service lists | [student_home.html](../../../web/templates/student_home.html) | Own supplied summaries and links; full aggregate remains deferred. **Existing anchor; aggregate deferred** |
| Appointments | `/appointments/` / AppointmentService.list_for | [appointments.html](../../../web/templates/appointments.html) | Own requests and optional invitations in all statuses. **Implemented / preserved** |
| New appointment | `/appointments/new; /appointments/times` / AppointmentService.directory/evaluate/submit | [appointment_new.html](../../../web/templates/appointment_new.html) | Faculty, required professors, optional students, purpose, duration, date, recommendations and manual proposals. **Implemented / preserved** |
| Appointment details | `/appointments/<id> and existing POST actions` / AppointmentService.detail/reschedule/cancel | [appointment_detail.html](../../../web/templates/appointment_detail.html) | Current revision approvals, permitted reschedule/cancel and retained history. **Implemented / preserved** |
| Appointment invitation | `/appointments/<id>; /decline-invitation` / AppointmentService.detail/decline_invitation | [appointment_detail.html](../../../web/templates/appointment_detail.html) | Participant-scoped optional invitation and own decline; no organizer privileges. **Implemented / preserved** |
| Room requests | `/rooms/` / RoomRequestService.list_for | [room_requests.html](../../../web/templates/room_requests.html) | Own/registered room activities and optional professor invitations. **Implemented / preserved** |
| New room request | `/rooms/new; /rooms/candidates; /<id>/revise` / RoomRequestService.recommend/submit; WaitingListService.join_room | [room_request_new.html](../../../web/templates/room_request_new.html) | Ranked rooms, constraints, participants, recurrence, revision and eligible queue consent. **Implemented / preserved** |
| Room request details | `/rooms/<id> and existing occurrence actions` / RoomRequestService.detail/cancel/cancel_occurrence | [room_request_detail.html](../../../web/templates/room_request_detail.html) | Faculty progress, exact room, actual participants, optional invitations, dates, cancellation and eligible feedback. **Implemented / preserved** |
| Room availability | `/rooms/availability/<room_id>` / RoomRequestService.availability | [room_availability.html](../../../web/templates/room_availability.html) | Authorized busy/free only, date selection and unresolved warnings. **Implemented / preserved** |
| Equipment requests | `/equipment/` / EquipmentService.list_for | [equipment_requests.html](../../../web/templates/equipment_requests.html) | Own requests, loans, recurring summaries and overdue warnings. **Implemented / preserved** |
| Equipment catalog | `/equipment/catalog` / EquipmentService.catalog/recommend/submit; WaitingListService.join_equipment | [equipment_catalog.html](../../../web/templates/equipment_catalog.html) | Faculty, exact quantities/specs, pickup/due, recurring preview, alternatives and eligible waiting entry. **Implemented / preserved** |
| Equipment loan details | `/equipment/<id> and permitted transitions` / EquipmentService.detail/cancel/intend_return/request_extension | [equipment_detail.html](../../../web/templates/equipment_detail.html) | Assets, actual collection/partial return, overdue, extensions, recurrence and reporting; custody stays staff-only. **Implemented / preserved** |
| Waiting lists | `/waiting-lists/; /refresh` / WaitingListService.list_for/refresh_for | [waiting_lists.html](../../../web/templates/waiting_lists.html) | Own contextual queues, actual policy and authorized recheck. **Implemented / preserved** |
| Waiting-list details | `/waiting-lists/<id>; /cancel` / WaitingListService.detail/cancel | [waiting_detail.html](../../../web/templates/waiting_detail.html) | Position, preapproval, assignment, consent, withdrawal and history. **Implemented / preserved** |
| Waiting-list policy | `/waiting-lists/policy` / WaitingListService.policy | [waiting_policy.html](../../../web/templates/waiting_policy.html) | Actual configured notice/version, FCFS limits, eligibility, privacy and assignment rules. **Implemented / preserved** |
| Feedback & issues | `/feedback/` / FeedbackService.list_for | [feedback_list.html](../../../web/templates/feedback_list.html) | Own private reports and server-scoped filters; eligible usage entry guidance. **Implemented / preserved** |
| Report resource issue | `/feedback/new/<kind>/<booking_id>` / FeedbackService.context/submit | [feedback_new.html](../../../web/templates/feedback_new.html) | Actually used resource, eligible categories, urgent problem flag, description and idempotent submit. **Implemented / preserved** |
| Feedback report details | `/feedback/<id>; /update` / FeedbackService.detail/update | [feedback_detail.html](../../../web/templates/feedback_detail.html) | Private original report, staff response, allowed clarification and status history. **Implemented / preserved** |
| University calendar | `/calendar/; /calendar/academic/<id>` / UniversityCalendarService.load/academic_detail | [university_calendar.html](../../../web/templates/university_calendar.html) | Month/week/day, dates, filters, authorized events, warnings and published academic details. **Implemented / preserved** |
| My schedule & blocks | `/appointments/calendar` / PersonalScheduleService.load; AppointmentService.block/unblock | [appointment_calendar.html](../../../web/templates/appointment_calendar.html) | Own timetable, month/week, weekends, optional attendance, private block creation/removal. **Implemented / preserved** |
| Notifications | `/notifications/; /feed; /read` / NotificationService.inbox/mark_read | [notifications.html](../../../web/templates/notifications.html) | Private destinations, explicit Read/Unread, individual/all-through-ID persisted actions. **Implemented / preserved** |
| Sign in | `/login; /logout` / AccountService; unchanged security.py | [login.html](../../../web/templates/login.html) | Provisioned credentials, CSRF, validation, sessions, logout and role redirects. **Implemented / preserved** |
| State gallery | `Existing responses and form state components` / Existing services and error handlers | [student_error.html](../../../web/templates/student_error.html) | Real empty/loading/invalid/conflict/private/offline/service-failure states; no standalone gallery route. **Real states implemented; gallery is reference only** |
